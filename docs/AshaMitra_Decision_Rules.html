How the engine decides

The clinical engine is deterministic — the same answers always produce the same triage band, byte-for-byte. No LLM sits in the diagnostic path. Rules are evaluated top-to-bottom; the first hard-stop match exits immediately as RED.

Hard-stop answer triggersহ্যাঁ · একবার · একটু · অনেক
Yellow answer triggersহ্যাঁ · মাঝে মাঝে · কিছুটা
Evaluation orderRules are evaluated top-to-bottom. First hard_stop match exits immediately with RED.
Multi-condition logicAND — all conditions in a rule's condition_set must be true for the rule to fire.
Band-lock ruleOnce RED is fired by any hard_stop rule, band is locked RED. No subsequent answer can downgrade it.
Fallback bandGREEN (when no rule fires)

Band resolution & referral

RuleBandConditionReferralAction
BAND-001 GREEN No hard_stop fired AND no YELLOW rule fired Home care Home care. Routine follow-up per module schedule. Counsel on warning signs. Record visit on ANMOL.
BAND-002 YELLOW No hard_stop fired AND at least one YELLOW rule fired PHC within 24 h Refer to PHC within 24 h. Follow up in 2 days. Counsel on escalation signs. Record on ANMOL.
BAND-003 RED Any hard_stop rule fired FRU / SNCU / DH immediately Refer FRU/SNCU/DH immediately (≤ 30–60 min). Call 108. Decision trace locked. MDSR hook triggered if applicable.

Reading a rule card

Each rule below shows: its ID, the triage band it fires, whether it is a HARD-STOP (irreversible RED) or a scored sign, the question (Bengali + English) and answer options, the deterministic logic, any escalation to a higher band, the action the ASHA must take, and the referral target.
